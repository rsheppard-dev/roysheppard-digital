# Design work

For any UI or visual design work on this site (new sections, layout changes, redesigns, polish, critiques), load these skills before editing:

- `impeccable` — primary design skill; use its matching sub-command (audit, critique, polish, etc.)
- `taste-skill` — keep pages and sections from looking templated
- `emil-design-eng` — whenever motion, hovers, transitions or interaction details are involved

This applies even when a different design skill (e.g. `/design`) was invoked directly.
